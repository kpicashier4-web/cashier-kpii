IMPORTANT: This is the corrected Version 12.

A) GitHub
1. Open repository KPICASHIER / kpi-cashier.
2. Open index.html.
3. Click the pencil Edit icon (NOT the three-dot menu).
4. Ctrl+A and replace the entire file with this index.html.
5. Commit changes to the branch used by GitHub Pages.
6. Wait for the green github-pages deployment.
7. Open the site and press Ctrl+F5.

B) Supabase
1. SQL Editor -> New query.
2. Paste ALL of SUPABASE_FINAL.sql.
3. Click Run.
4. Wait for Success.

C) Expected result
Admin:
- Can enter more than one KPI for the same employee/date.
- Can edit/delete all employees.
- Can clear a whole month.
- Has Monthly Excel.

Employee:
- Sees only own records.
- Can enter only once per day.
- Cannot edit/delete.
- Date is automatic.
- Success message: Thanks For Today.
